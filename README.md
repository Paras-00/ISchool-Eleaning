# iSchool Learning

iSchool Learning is an e-learning platform inspired by Coursera, built using **PHP, HTML, CSS, and JavaScript**. Users can browse courses, enroll in classes, and access learning materials online.

## Features
- Browse and search courses
- Enroll in courses and track progress
- Interactive learning materials (videos, PDFs)
- User authentication and profiles
- Responsive design for desktop and mobile

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL 
- **Optional:** Bootstrap for styling, jQuery for interactivity
